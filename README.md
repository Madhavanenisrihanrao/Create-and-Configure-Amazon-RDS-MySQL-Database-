**Objective:**

To create and configure an Amazon RDS MySQL database instance, establish connectivity from a local MacBook using the MySQL command-line client, create a database and table, insert student records, and retrieve the records using SQL queries.

**Practical Demonstration Includes:**

1. Creating an Amazon RDS MySQL database instance.
2. Configuring database credentials and instance class.
3. Configuring storage and VPC connectivity.
4. Configuring security group inbound rules for MySQL (TCP 3306).
5. Connecting to Amazon RDS from macOS Terminal.
6. Creating the StudentDB database.
7. Creating the Student table.
8. Inserting five student records.
9. Executing SELECT queries to retrieve the records.

**SQL Commands Demonstrated:**
- CREATE DATABASE
- USE
- CREATE TABLE
- INSERT INTO
- DESCRIBE
- SELECT

**Result:**

Successfully created and configured an Amazon RDS MySQL database, connected to it from a local MacBook, created the StudentDB database and Student table, inserted five student records, and retrieved all five records successfully.

**Tools & Technologies:** Amazon Web Services (AWS), Amazon RDS, MySQL, macOS Terminal.
